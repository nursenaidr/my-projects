# Lab 4 - Robotic Arm

A Three.js robotic arm built with a scene graph hierarchy:
base -> shoulder -> elbow -> wrist -> palm -> fingers.

## Controls
- Q / A: rotate shoulder
- W / S: rotate elbow
- E / D: rotate wrist
- Mouse: orbit the camera

## How to run
```bash
npm install
npm run dev
```
Then open the localhost link that Vite prints.
